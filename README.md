# Portfolio Website — Original Design

A responsive HTML and CSS portfolio by Lewis Xiong. This early web design project includes a personal introduction, a school photograph, and a GitHub profile link.

## Run locally

From the repository root:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. On Windows, use `py -m http.server 8000`.

## Files

- `index.html` — page content and navigation.
- `assets/css/style.css` — responsive layout and typography.
- `assets/images/` — images used by the page.
- `assets/fonts/` — the local font.

No package installation or build step is required.
